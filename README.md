# CargoLink 3D

Modelo 3D interactivo de CargoLink, una unidad modular reutilizable para el transporte de mercancías por carretera. Prototipo de un trabajo universitario de Design Thinking.

**Ver en línea:** https://cargolink-project.github.io

- Tamaños S, M y L, puertas animadas, apilado y puntos de interés.
- Carga de unidades en un semirremolque de 13,6 m.
- Calculadora orientativa de CO₂ y embalaje evitado, con supuestos editables y fuentes.

`index.html` es autónomo: lleva Three.js r165 (licencia MIT) incrustado, así que funciona sin conexión y también se puede abrir con doble clic.
